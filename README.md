
### PrepQ: Intelligent Mock Interview & Job Matching Agent

**PrepQ** is an AI-powered mock interview and career acceleration platform built on **Amazon Q**. It automates the entire job-seeking pipeline by parsing resumes for **ATS optimization**, dynamically generating **MCQ assessments**, and providing instant feedback. The agent matches candidates with live job openings and enables direct application via **automated HR emailing**.

### 🎯 The Problem We Solved

Traditional recruitment pipelines are slow, fragmented, and inefficient. Candidates struggle to tailor their profiles to applicant tracking systems (ATS), lack realistic structured interview practice, and spend hours manually hunting for jobs. 

**PrepQ bridges this gap by delivering:** 

* **Personalized Prep:** Dynamic mock interviews built strictly around candidate profiles.
* **Auto-Evaluation:** Instant, objective scoring to eliminate subjective feedback delays.
* **Resume Optimization:** Actionable insight generation to boost ATS keyword match rates.
* **Frictionless Outreach:** Direct-to-HR automated email pipelines for open job roles.

### ✨ Key Features

* **AI Resume Parsing & ATS Optimization:** Extracts skills and experience metrics from PDF/DOCX uploads while generating optimization insights.
* **Dynamic MCQ Assessment Module:** Dynamically spins up role-specific technical/behavioral tests tailored to the candidate's exact background.
* **Automated Scoring & Domain Mapping:** Instantly evaluates scores post-assessment and recommends the candidate's absolute best-fit job domain.
* **Live Job Aggregation:** Hits live recruitment APIs to fetch open roles that match the candidate’s newly optimized profile.
* **Direct HR Outreach Automation:** Enables candidates to seamlessly apply to open opportunities by dispatching automated outreach emails straight to hiring managers.
* **Smart Notification System:** Keeps candidates informed with real-time updates regarding changing hiring environments.

### 🚀 How It Works

[ Upload Resume ] ➔ [ Resume Analysis ] ➔ [ MCQ Mock Interview ] ➔ [ Evaluation & Scoring ]
                                                                             │
[ Direct HR Outreach ] 🗲 [ Best-Fit Job Match ] ➔ [ Resume Improvement Insights ]

1. **Upload Resume:** Candidate uploads an existing profile in PDF or DOCX format.
2. **Resume Analysis:** The engine strips away document formatting to extract skills, history, and core ATS keywords.
3. **Mock Interview:** The system provisions a rapid-fire, role-specific, multiple-choice testing suite.
4. **Evaluation:** Automated test execution provides immediate scoring breakdowns and gap analysis.
5. **Resume Improvement:** Candidates receive clear, actionable textual recommendations to upgrade their resume score.
6. **Best-Fit Jobs:** The system queries live job boards to filter roles fitting the user's validated performance tier.
7. **Direct HR Connection:** Candidates trigger an automated mail script to dispatch their credentials cleanly to HR managers.
8. **Notifications:** Real-time event hooks supply rapid alerts regarding job changes and hiring status.

### 🛠 Tech Stack

* **Frontend:** React.js
* **Backend:** Node.js + Express
* **Database:** MongoDB
* **AI/ML Orchestration:** Amazon Q CLI + MCP (Model Context Protocol)
* **Document Processing:** pdf-parse / docx-parser
* **Email Service Suite:** Nodemailer
* **Data Ingestion:** External Recruitment APIs
